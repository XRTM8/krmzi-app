# قرمزي برو | Krmzi Pro
تطبيق بث ومتابعة مسلسلات الدراما التركية من موقع `krmzi.org` بدون أي إعلانات نهائياً، وبواجهة عصرية مستوحاة من كبرى منصات البث العالمية (Netflix / Shahid).

---

## 🌟 مميزات التطبيق

1. **مشاهدة بدون إعلانات نهائياً (Ad-Free Experience):**
   - استخراج روابط البث المباشر المباشرة (**1080p Full HD**, 720p, 480p) وتشغيلها في مشغل الفيديو الأصلي (Native Video Player).
   - حظر كامل للإعلانات المنبثقة والنوافذ الإجبارية وتحويلات الروابط (Zero Popups & Redirects).
2. **مشغل فيديو احترافي متقدم:**
   - تحكم كامل بالدقة (1080p, 720p, 480p, 360p).
   - تقديم وتأخير 10 ثوانٍ بضغطة زر أو عبر أسهم لوحة المفاتيح.
   - التحكم في سرعة العرض (0.75x, 1x, 1.25x, 1.5x, 2x).
   - دعم نافذة العرض المصغرة (Picture-in-Picture).
   - زر تحميل مباشر للحلقة بضغطة زر واحدة.
3. **مكتبة متكاملة ومحدثة تلقائياً:**
   - جلب أحدث الحلقات المضافة فور نزولها على الموقع.
   - تصفح قائمة المسلسلات والاطلاع على قصتها وجميع حلقاتها بترتيب تصاعدي.
   - محرك بحث فوري وسريع عن المسلسلات.
4. **ميزات شخصية:**
   - **سجل المشاهدة (Watch History):** حفظ تلقائي للنقطة التي توقفت عندها لكل حلقة لإمكانية الاستئناف.
   - **المفضلة (Watchlist):** حفظ المسلسلات المفضلة للوصول إليها بنقرة واحدة.
5. **دعم الهواتف والأجهزة اللوحية (PWA Ready):**
   - تصميم متجاوب 100% يعمل على الهواتف، الأجهزة اللوحية، الكمبيوتر والشاشات الذكية.
   - إمكانية التثبيت كتطبيق مستقل (Install as PWA) على أندرويد و iOS.

## 🚀 طريقة التشغيل (بنقرة واحدة)

### لمستخدمي Windows:
* قم بالنقر مرتين على الملف:
  ```
  start.bat
  ```
  سيتم فتح التطبيق مباشرة في متصفحك على الرابط: `http://localhost:3000`.

### عبر موجه الأوامر (Terminal / CMD):
```bash
npm start
```
أو:
```bash
node server.js
```

## 📱 تحويل المشروع إلى تطبيق هاتف (APK / iOS)

المشروع مبني ليكون متوافقاً تماماً مع التحويل إلى تطبيق جوال أصلي عبر:
1. **تثبيت مباشر PWA (الأسهل):**
   افتح الرابط `http://localhost:3000` (أو بعد رفعه على خادم سحابي) من متصفح الهاتف (Chrome أو Safari)، ثم اختر من القائمة **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)** وسيتحول فوراً لتطبيق مستقل بدون شريط المتصفح.
2. **بناء APK عبر Capacitor:**
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init
   npx cap add android
   npx cap open android
   ```
   ثم استخراج ملف الـ APK النهائي من Android Studio.

## 🛠️ البنية التقنية

* **الباك إند (Backend API):** Node.js + Express (معالجة واستخراج الروابط، تخطي التشفير، واستخراج دفقات الفيديو من OK.ru والسيرفرات الخارجية).
* **الفرونت إند (Frontend UI):** Vanilla JavaScript (ES6+), HTML5 Custom Video Engine, CSS3 Dark Glassmorphism, Google Tajawal Font, FontAwesome Icons.
